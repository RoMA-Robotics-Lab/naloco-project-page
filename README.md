# NALOCO project page

Project website for **Noise-Attenuated Legged Locomotion via Noise-Proxy-Informed Residual Actions**.

This repository contains the static project page, manuscript, figures, and experimental video. Research implementation code is not included.

## Files

- `index.html`: page content
- `style.css`: responsive layout
- `script.js`: citation-copy interaction
- `assets/`: manuscript, figures, and video

## Hosting

Serve the repository root as a static website. GitHub Pages uses the `main` branch and `/` directory. `.nojekyll` preserves the static files without Jekyll processing.

For anonymous review, share the Anonymous 4open website address rather than the original repository or GitHub Pages address. Check the manuscript and audiovisual assets separately for identifying information; text redaction does not anonymize embedded media.
